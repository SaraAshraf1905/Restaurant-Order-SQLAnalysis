**Restaurant Order Analysis | SQL**
A SQL-based data analysis project focused on exploring restaurant order data and turning raw data into useful business insights.
I used **SQL** to analyze orders, identify top-selling products, examine sales patterns, and uncover trends across different menu items and categories.
The project involved data exploration, filtering, aggregations, joins, subqueries,CTEs, and other SQL techniques to answer real-world business questions.

**Tools:** SQL Server, SQL
**Focus:** Data Analysis · Sales Insights · Business Intelligence
